# D2 AI 教练对话 — 实现计划

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 接入 DeepSeek API，实现知识点讲解 AI 对话，支持多轮对话 + SSE 流式输出。

**Architecture:** 2 张新表，遵循四层模式。SSE 通过 FastAPI `StreamingResponse` + `httpx` 流式转发 DeepSeek。前端 EventSource 消费 SSE + 独立对话页。

**Tech Stack:** PostgreSQL, FastAPI (SSE), DeepSeek API, httpx, React + Zustand

**Spec:** `docs/superpowers/specs/2026-05-16-d2-ai-chat-design.md`

**环境约束:** Python 用 `conda run -n ai_code_assistant_env`，前端 `cd frontend`

## Task 3: Schema + Service + Router

### Schema (`schemas/ai_chat.py`)

```python
from datetime import datetime
from typing import Optional
from uuid import UUID
from pydantic import BaseModel

class ConversationCreate(BaseModel):
    knowledge_node_id: Optional[UUID] = None
    title: Optional[str] = "新对话"

class ConversationBrief(BaseModel):
    id: UUID; title: str; knowledge_node_id: Optional[UUID] = None
    created_at: datetime; updated_at: datetime
    class Config: from_attributes = True

class MessageItem(BaseModel):
    id: UUID; role: str; content: str; created_at: datetime
    class Config: from_attributes = True

class StreamRequest(BaseModel):
    content: str
```

### Service (`services/ai_service.py`)

核心方法：

```python
class AIService:
    def __init__(self, db: AsyncSession): ...
    
    async def list_conversations(self, user_id: UUID) -> list[ConversationBrief]
    async def create_conversation(self, user_id: UUID, data: ConversationCreate) -> AIConversation
    async def get_messages(self, conversation_id: UUID) -> list[MessageItem]
    async def delete_conversation(self, conversation_id: UUID, user_id: UUID)
    async def stream_chat(self, conversation_id: UUID, user_message: str) -> AsyncGenerator[str, None]:
        # 1. 查会话 + 知识点 → 构建 system_prompt
        # 2. 查最近 10 条历史消息
        # 3. 构建 messages = [system, ...history, user]
        # 4. httpx.stream("POST", "https://api.deepseek.com/v1/chat/completions", json={...})
        # 5. 逐 chunk yield data.choices[0].delta.content
        # 6. 流结束后保存 user + assistant 消息到 DB
```

### Router (`routers/ai_chat.py`)

```python
router = APIRouter(prefix="/api/v1/ai", tags=["AI对话"])

GET    /conversations              # list
POST   /conversations              # create
GET    /conversations/{id}/messages # history
DELETE /conversations/{id}         # delete

POST   /conversations/{id}/stream  # SSE 流式
    → StreamingResponse(ai_service.stream_chat(id, request.content), media_type="text/event-stream")
```

## Task 4: 前端 — SSE 流式 + 对话页面

### Store 补全 (`stores/aiChatStore.ts`)

```typescript
// 基于 A2 骨架补全
interface AIChatState {
  conversations: ConversationBrief[]
  currentId: string | null
  messages: MessageItem[]
  isStreaming: boolean
  streamingContent: string
  
  fetchConversations: () => Promise<void>
  createConversation: (knowledgeNodeId?: string, title?: string) => Promise<string>
  fetchMessages: (id: string) => Promise<void>
  sendMessage: (content: string) => Promise<void>  // SSE
  deleteConversation: (id: string) => Promise<void>
}
```

**sendMessage 核心逻辑**：

```typescript
// POST stream 端点，用 EventSource 消费
const eventSource = new EventSource(
  `${API}/ai/conversations/${convId}/stream?content=${encodeURIComponent(msg)}`
)
eventSource.onmessage = (e) => {
  if (e.data === '[DONE]') { eventSource.close(); set({ isStreaming: false }) }
  else { set((s) => ({ streamingContent: s.streamingContent + e.data })) }
}
```

### AIChatPage (`pages/AIChatPage.tsx`)

布局：左侧会话列表 (w-72) + 右侧聊天区。对话气泡（user 右蓝 / assistant 左灰），流式输出时 AI 消息实时增长。

### InlineChat 组件 (`components/InlineChat.tsx`)

知识图谱详情页底部折叠面板。`props: { knowledgeNodeId, knowledgeNodeTitle }`。打开时自动创建关联该知识点的会话（如果已存在则复用）。

### KnowledgeTreePage 底部添加 InlineChat

详情页 Tab 栏右侧加「问 AI」按钮，点击展开 InlineChat。
