三、API 层修复设计

响应格式统一

当前（错误）: response.data.data → undefined → TypeError

目标（正确）: response.data → FastAPI 直接返回的 JSON

修改点:

  • authStore.ts:34 — response.data.data → response.data
  • authStore.ts:41 — userResponse.data.data → userResponse.data
  • authStore.ts:78 — response.data.data → response.data

新增 API 类型文件 src/types/api.ts — 统一定义后端响应类型

四、错误处理架构

三层防御体系

第一层：全局 ErrorBoundary（App 根节点）

<ErrorBoundary>
  <BrowserRouter>
    <App />
  </BrowserRouter>
</ErrorBoundary>

第二层：API 错误拦截（api.ts）

  • 401 → 清理 token → 使用 React Router navigate('/login')
  • 500 → 显示友好错误信息

第三层：组件错误边界（关键页面）

  • LoginPage、HomePage 各自包裹 ErrorBoundary

五、样式系统

Tailwind 完整集成

安装依赖: tailwindcss postcss autoprefixer

配置:

  content: ["./index.html", "./src/**/*.{js,ts,jsx,tsx}"]
  theme: { extend: { colors: { primary: {...} } } }

postcss.config.js:
  plugins: { tailwindcss: {}, autoprefixer: {} }

清理: 删除 index.css 中所有 BEM 类名（.title/.card/.input 等）

App.css: 重写为平铺 CSS，去除嵌套语法
