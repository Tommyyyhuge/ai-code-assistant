一、产品概述
1.1 项目背景
信息学竞赛（Olympiad in Informatics，简称 OI）和大学生程序设计竞赛是全球范围内规模最大的编程竞赛体系。在中国，OI 竞赛体系涵盖 CSP-J/S、NOIP、NOI、APIO 直至 IOI，形成了一条完整的升学与选拔通道。与此同时，蓝桥杯全国软件和信息技术专业人才大赛每年吸引超过 20 万大学生参与，是高校最具影响力的编程竞赛之一。
除竞赛选手外，大量编程自学者也面临"想学但不知从何下手"的困境。他们缺乏系统的学习路径、专业的指导和及时的反馈，在网上零散的学习资源中反复碰壁。
据不完全统计，中国每年参加 CSP-J/S 的学生超过 30 万人，蓝桥杯参赛人数超过 20 万人，再加上 ACM-ICPC 校队成员、编程自学者，整体目标用户群体超过 80 万人。然而，现有工具存在以下结构性问题：
题目资源高度分散：OI 选手在洛谷、Codeforces 间切换，蓝桥杯选手找不到针对性练习
缺乏系统性的知识学习：网上的教程零散，不成体系，自学者难以建立完整的知识结构
错误反馈体验差：提交 WA 或 TLE 后，缺乏针对性的诊断和指导
现有 AI 工具不适合学习场景：GitHub Copilot、ChatGPT 直接生成代码，跳过了思考过程，不利于能力培养
蓝桥杯等竞赛缺乏专门训练平台：现有 OJ 主要面向 OI/ACM，缺少蓝桥杯风格的题目和知识体系
1.2 产品愿景与定位
让每一个想学编程的人，都有一个 24 小时在线的专业 AI 教练。
AI_code_assisstant 是一款面向编程竞赛选手和自学者的 Web 端 AI 编程学习平台。平台以"知识体系 + 引导式练习"为核心理念，不仅帮助用户解决"这道题怎么做"，更重要的是回答"这个知识点是什么、怎么用、什么时候用"。
平台覆盖三大核心场景：
竞赛训练：OI（CSP-J/S 到 NOI）、ACM-ICPC、蓝桥杯等竞赛的题目练习和评测
知识学习：系统化的算法与数据结构知识点体系，配套讲解和练习题
自学成长：从零基础到进阶的完整学习路径，AI 教练全程陪伴

三、核心功能模块
产品由五大核心模块构成，形成"学习知识 -> 练习题目 -> 评测反馈 -> AI辅导 -> 持续提升"的完整学习闭环：
3.1 题库中心（Problem Hub）
题库中心是平台的内容基础，负责汇聚、管理和呈现编程题目。采用混合策略获取题目：优先使用 OJ 平台开放 API，辅以公开数据爬取和原创题目补充。
3.1.1 题目聚合
首批接入平台：洛谷（中文 OJ，题目质量高）、Codeforces（国际竞赛平台，题量丰富）、LibreOJ（开源 OJ，数据开放）
蓝桥杯专题：整理蓝桥杯历年真题（省赛/国赛），按知识点分类，形成蓝桥杯专属训练集
题目字段：题号、标题、难度分（1-10）、算法标签、时间/空间限制、题目描述（Markdown）、输入输出格式、样例数据、提示信息
3.1.2 标签体系
一级分类：语法基础、模拟、排序、搜索、贪心、动态规划、图论、数论、字符串、数据结构、计算几何
蓝桥杯特色标签：简单模拟、字符串处理、枚举、递归、基础数学、日期计算等蓝桥杯高频考点
3.1.3 搜索与筛选
组合筛选：按难度区间、算法标签、来源 OJ、是否有题解、是否已做等条件筛选
蓝桥杯模式：一键筛选蓝桥杯真题和省赛/国赛模拟题
3.2 在线评测引擎（Judge Engine）
评测引擎是平台的技术核心，负责编译、运行用户代码并与标准答案比对。采用容器化沙箱确保安全性。
3.2.1 编程语言支持
C++17/G++11（OI/ACM 主流语言，优先支持）
Python 3.10+（入门选手友好，蓝桥杯允许语言）
Java 17（部分学校教学语言，蓝桥杯允许语言）
3.2.2 评测流程
用户提交代码 -> 沙箱编译 -> 逐组测试数据运行 -> 结果判定 -> 生成评测报告
评测状态：Pending、Compiling、Running、AC、WA、TLE、MLE、RE、CE
3.2.3 沙箱安全
基于 Docker 容器隔离，每个评测任务独立容器
资源限制：CPU 时间、内存、输出大小、进程数严格限制
网络隔离：评测容器禁止网络访问
3.3 AI 竞赛教练（AI Coach）
AI 竞赛教练是本产品的核心差异化功能。采用"引导式教学"模式，通过苏格拉底式提问帮助用户理解问题、找到思路。
3.3.1 设计原则
原则一：永不直接给出可 AC 的完整代码。AI 的角色是教练，不是枪手。
原则二：先诊断，后引导。先分析错误类型，再有针对性地给出提示。
原则三：分级提示。根据用户追问深度逐步解锁更多提示。
原则四：因材施教。根据用户当前水平和历史记录调整提示深度。
3.3.2 三级提示系统
3.3.3 错因诊断
WA 分析：对比用户输出与期望输出的差异点
TLE 分析：分析算法复杂度是否超标，给出优化方向
MLE 分析：检查内存占用模式，提示空间优化策略
RE 分析：识别常见运行时错误（数组越界、空指针、栈溢出等）
3.3.4 AI 模型配置
默认模型：DeepSeek V3（性价比高，中文能力强）
可扩展：用户可配置自己的 API Key 接入 GPT-4o、Claude、Qwen 等模型
System Prompt 内置：为竞赛场景专门优化的 System Prompt
3.4 知识学习中心（Knowledge Hub）
"不只是告诉你答案，而是教会你方法。" — 知识学习中心是 AI_code_assisstant 区别于纯刷题平台的核心模块。
知识学习中心提供系统化的编程知识学习体系。当用户遇到不熟悉的算法或数据结构时，可以在这里找到完整的学习资源：从概念讲解到代码实现，从简单例题到进阶练习。
3.4.1 知识图谱
知识点以树状结构组织，形成完整的编程知识图谱
一级分类：编程基础、基础算法、数据结构、进阶算法、数学基础、竞赛专题
示例 - 动态规划分支：DP 概述 -> 线性 DP -> 背包问题 -> 区间 DP -> 树形 DP -> 状压 DP -> 数位 DP
每个知识点显示：前置知识（必须先学的）、后续知识（学完后可以学的）、相关题目
蓝桥杯专项知识路径：蓝桥杯高频考点知识专题（日期问题、全排列、进制转换、大数运算等）
3.4.2 知识内容
每个知识点包含：概念定义、核心思想、适用场景、算法步骤、代码模板（C++/Python/Java）、时间/空间复杂度分析
交互式讲解：AI 教练可以针对知识点进行互动式问答，确保用户真正理解
可视化演示：算法执行过程的可视化动画（如排序过程、图的遍历、DP 填表过程）
易错点提示：总结该知识点常见的错误和坑点
3.4.3 配套练习
每个知识点关联 3-5 道配套练习题，从入门到进阶递进
练习推荐逻辑：学习完知识点后自动推荐第一道题；完成后根据正确率和用时推荐下一道
蓝桥杯专项：蓝桥杯知识点的配套练习直接使用历年真题或仿真题
薄弱项自动推荐：AI 分析用户刷题数据，自动推荐薄弱环节对应的知识点和练习
3.4.4 学习路径
预置学习路径：提供多条官方学习路线
  - OI 入门路线：语法基础 -> 模拟 -> 排序 -> 搜索 -> 贪心 -> 简单 DP（适合 CSP-J）
  - OI 提高路线：图论 -> 树形 DP -> 线段树 -> 网络流 -> 字符串算法（适合 CSP-S/NOIP）
  - 蓝桥杯备赛路线：基础语法 -> 简单算法 -> 蓝桥杯真题专题 -> 模拟赛（适合大学生）
  - 零基础自学路线：编程入门 -> 基础算法 -> 数据结构 -> 进阶算法（适合自学者）
自定义路径：用户可根据自己的目标选择或调整学习路径
路径进度追踪：显示每条路径的完成百分比，已掌握/学习中/未开始的知识点状态
3.5 用户系统与进度管理
用户注册：支持邮箱注册和第三方登录（GitHub、Google）
刷题记录：记录每道题的提交历史、最终状态、用时
能力评估：基于 Elo 评分系统的竞赛能力分
薄弱分析：自动统计用户在各类别题目上的正确率，生成薄弱环节报告
训练计划：根据目标赛事或学习目标生成阶段性训练计划，每周更新
成就系统：连续打卡、完成题数里程碑、攻克难题等成就激励
